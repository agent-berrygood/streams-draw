# 스트림스 숫자 뽑기

스트림스(Streams) 보드게임의 숫자 타일을 대신 뽑아주는 웹앱입니다. 시니어분들이 보기 편하도록 큰 글씨, 음성 안내, 큰 버튼으로 만들었습니다.

## 기능

- 실제 타일 구성과 같은 40장: 1~30 한 장씩, 11~19는 한 장씩 더, 조커(★) 1장
- 한 게임에 20번 뽑기, 같은 타일은 다시 나오지 않음
- 뽑을 때마다 숫자를 두 번 읽어줌 (소리 켜기/끄기, 다시 듣기)
- 바로 전 숫자, 나온 순서 20칸 표시
- 되돌리기: 잘못 눌렀을 때 한 단계 취소 (다시 뽑으면 같은 숫자가 나옴)
- 새로고침해도 진행 중인 게임이 유지됨
- 게임 중 화면이 꺼지지 않음 (지원 브라우저)
- 점수 계산표
- 노트북에서는 스페이스바나 엔터로도 뽑기 가능

### 내 보드판 (`board.html`)

- 물줄기를 따라 이어진 20칸 보드판 (가로 화면 5×4, 세로 화면 4×5)
- 칸을 누르고 숫자를 고르면 들어감. 같은 기기에서 방금 뽑은 숫자는 버튼 하나로 넣기
- 이미 다 쓴 숫자는 고를 수 없음 (11~19는 두 번까지)
- 이어진 물줄기마다 색을 칠하고 점수를 자동 계산. 조커는 가장 유리한 숫자로 계산
- 종이 보드판 인쇄: 단면(1게임 1쪽) 또는 양면(1게임·2게임 앞뒤 2쪽), A4 가로에 이름·점수 칸과 점수표 포함

## 파일

빌드 과정 없는 정적 사이트입니다.

```
index.html   화면 구조
style.css    디자인
app.js       뽑기 로직
board.html   보드판 화면
board.css    보드판 디자인
board.js     보드판 그리기와 점수 계산
favicon.svg  아이콘
```

## 배포 (GitHub → Vercel)

1. 이 폴더를 GitHub 저장소로 올립니다.
2. Vercel에서 **Add New → Project**로 저장소를 가져옵니다.
3. Framework Preset은 **Other**, Build Command와 Output Directory는 비워 둔 채 **Deploy**를 누릅니다.

로컬에서 확인하려면 `index.html`을 브라우저로 열면 됩니다.
